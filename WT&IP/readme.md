## Executive Summary

NEXUS is a comprehensive academic repository showcasing practical implementations of core web-development concepts. It brings together HTML5 structure, CSS3 styling, and client-side JavaScript in an interactive learning environment. The project emphasizes hands-on experimentation, readable source code, and immediate visual feedback without depending on external libraries or frameworks.

## Technical Architecture and UI/UX Design

The repository uses a lightweight, component-free architecture with a custom **Dark Glassmorphism** interface.

- **Live Execution Environment:** A dual-panel workspace presents source code alongside its rendered output. Code is executed in an isolated `iframe` through the `srcdoc` attribute, allowing experiments to be viewed directly in the browser.
- **Cinematic Visual Design:** A near-black background (`#050505`), burgundy and soft-pink radial glows (`#800020` and `#d4a3b3`), translucent surfaces, `backdrop-filter`, and subtle keyframe animations create a consistent visual identity.
- **Responsive Dashboard:** CSS Grid and Flexbox organize the interface for different screen sizes, supporting clear navigation and a practical coding workspace.

## Comprehensive Module Breakdown

### I. HTML5 Foundation — 15 Programs

This module covers the structure and semantic foundations of web pages.

- **Document Structure:** Headings, paragraphs, lists, semantic elements, and embedded content.
- **Forms and Tables:** Tables with merged cells, student registration forms, and modern HTML5 input types such as email, date, number, and password.
- **Multimedia and Navigation:** Images, hyperlinks, audio, video, and iframes.

### II. CSS3 Visual Engine — 75 Programs

This module explores layout, responsive design, and visual presentation.

- **Layout Systems:** Flexbox, CSS Grid, multi-column layouts, positioning, and mobile-first responsive design.
- **Styling Fundamentals:** Selectors, inheritance, specificity, the box model, typography, colors, backgrounds, borders, shadows, and CSS variables.
- **Visual Effects:** Gradients, opacity, filters, pseudo-classes, pseudo-elements, transitions, transformations, and keyframe animations.
- **Responsive Interfaces:** Navigation menus, galleries, cards, dashboards, and page layouts adapted to different viewport sizes.

### III. JavaScript Logic Controller — 272 Programs

This module develops programming logic and interactive browser experiences.

- **Core JavaScript:** Variables, operators, functions, arrays, strings, objects, ES6+ syntax, mathematical operations, and algorithmic problem-solving.
- **DOM Manipulation:** Dynamic element creation and removal, content and style updates, tables, dropdowns, modals, accordions, tabs, and image galleries.
- **Events and Interaction:** Mouse, keyboard, and form events, including event bubbling, capturing, and delegation.
- **Forms and Validation:** Question-specific form interfaces and client-side validation using appropriate checks and regular expressions.
- **Browser APIs and Storage:** Window, Location, and Navigator objects, LocalStorage, SessionStorage, and interactive features that preserve data.
- **Mini Projects:** Practical applications such as calculators, timers, quizzes, task lists, grade calculators, BMI calculators, and other question-specific exercises.

## Usage Instructions

1. Open `index.html` in a web browser to access the NEXUS dashboard.
2. Select the required technology section: HTML, CSS, or JavaScript.
3. Choose an experiment from the program list.
4. Review or edit the code in the **Source Code** panel.
5. Click **Run Code** to execute the experiment and inspect the result in the live output panel.
